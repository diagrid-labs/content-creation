# Content Creation skills for Diagrid

This repo contains Claude skills to help with content creation.

## Usage

Example prompt:

"Create a blog post that explains how the Dapr workflow persists its state."

You will be asked several questions about the target audience, intent, and call to actions. 
The result is a markdown file, see [this example](/blog-posts/dapr-workflow-state-persistence.md) that serves as a starting point for the blog post. Use this file to iterate further with Claude.
