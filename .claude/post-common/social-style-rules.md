# Social Style Rules

Conventions for social media posts generated by the `write-social-post` skill and validated by `review-social-post`. These rules apply only to social posts; blog rules in [style-rules.md](style-rules.md) still cover blog content.

## Canonical Diagrid hashtag list

When picking hashtags for X, LinkedIn, or Bluesky, draw from this list. Pick tags that are topic-relevant; do not invent new tags.

- `#dapr`
- `#kubernetes`
- `#workflow`
- `#aiagents`
- `#microservices`
- `#cloudnative`
- `#dotnet`
- `#golang`
- `#java`
- `#python`

## Tag selection rule

- X: 2-3 tags from the canonical list
- LinkedIn: 3-5 tags from the canonical list
- Bluesky: 1-2 tags from the canonical list
- Reddit, Dapr Discord, Dev.to: no inline hashtags

## Inherited rules

The following rules from [style-rules.md](style-rules.md) apply to every social post:

- Banned words: journey, dive, delve into, jump into, pivotal, underscore, harness, realm, illuminate, master.
- Do not use em dashes (or en dashes / double hyphens used as em dashes).
- Title rules (no two-sentence colon, no "From ... To ..." structure) apply to Reddit and Discord titles.

The blog-post rule "do not use emojis" does NOT apply to social posts. Per-platform emoji policy in the table above takes precedence.

## Per-platform writing guidance

### X
- Lead with the hook, not the link.
- Single-sentence opener carries the post.
- Place the link at the end so the hook is read first.
- Use 2-3 lowercase hashtags from the canonical list.
- One handle mention is fine; two is too many.

### LinkedIn
- The first line is the hook. Readers see only the first line before "see more".
- Use short paragraphs (1-2 sentences) and blank lines between them.
- Place the link at the end of the post.
- 3-5 mixed-case hashtags at the end (e.g., `#Dapr`, `#Kubernetes`).
- Sound like a person, not a press release.

### Bluesky
- Casual and technical at the same time.
- Hook-first, link last.
- Hashtags are plain text on Bluesky; 1-2 lowercase tags at most.
- Mentions use full domain handle (`@diagrid.io`).

### Reddit
- No marketing language. Reddit downvotes promotional tone.
- Title states the technical detail or question, not the benefit.
- Body explains the technical context. The link goes inside the body, naturally.
- No hashtags, no emojis, no handle mentions.
- Tone matches the subreddit if one is supplied (e.g., r/golang expects Go-focused phrasing).

### Dapr Discord
- Community tone, conversational, not promotional.
- Title states what the message is about (forum-style listing).
- Body is short and to the point; the link goes inside the body.
- At most one emoji.
- No hashtags, no handle mentions.

### Dev.to
- Forum-style: a title (max 120 chars) and a body share blurb (max 500 chars) pointing readers to the canonical article.
- Title states the technical detail, not a marketing benefit.
- Body leads with the technical takeaway, not the brand.
- Link at the end of the body.
- No inline hashtags (Dev.to uses front-matter tags, which are out of scope for this skill).
- One handle mention only when natural.
