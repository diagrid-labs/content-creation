# Content Creation Agent

This repository contains Claude Code skills for creating content at Diagrid.

## Available Skills

### `/blog-post`

Create a blog post template using an interview-driven approach based on the Diataxis framework. Run `/blog-post` (optionally with a topic) to start an interactive interview that produces a structured markdown template tailored to one of four document types: Tutorial, How-to, Explanation, or Reference.
